# Smart Procurement Platform — Farmer UI Frontend

A modern, responsive, mobile-first React application built for farmers in the Smart Procurement Platform.

## Technology Stack
- **React.js 18 / Vite**
- **Tailwind CSS v4**
- **React Router DOM**
- **Axios** (Centralized API service with Spring Boot proxy & fallback mock layer)
- **Lucide React Icons**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```

## Complete SIH Demonstration Workflow
`Language Selection -> Registration -> Login -> Farmer Profile -> Add Crop -> Find Centres -> Smart Recommendation -> Select Centre -> Select Slot -> Booking Confirmation -> Digital Token -> Queue Tracking -> Smart Departure Recommendation -> Procurement Status -> Payment Status -> Notifications`
